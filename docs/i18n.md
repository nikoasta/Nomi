# Interface localization

Nomi's interface strings live in dictionaries instead of component files. This keeps the Chinese-first upstream easy to merge while supporting Chinese, English, and Russian in the app.

## Supported locales

- `zh-CN`
- `en`
- `ru`

The selected interface language is stored under `nomi.interface-language`. Runtime code can read the current language with `getRuntimeLocale()` when it is outside React.

## Where strings go

- Shared app strings: `src/i18n/translations.ts`
- Onboarding and model setup strings: `src/ui/onboarding/onboardingI18n.ts`
- Canvas/node strings: `src/workbench/generationCanvas/canvasI18n.ts`
- 3D scene editor strings: `src/workbench/generationCanvas/nodes/scene3d/scene3dI18n.ts`

Keep new user-visible strings out of components. If upstream adds a Chinese label, placeholder, dialog, toast, or error, move the Chinese source into the matching dictionary and add English and Russian entries at the same time.

## How to translate code

Use `useI18n()` in React components:

```tsx
const { t } = useI18n()
return <button aria-label={t('window.close')}>{t('common.close')}</button>
```

Use a local translator for isolated high-churn surfaces:

```ts
canvasRuntimeTranslate('reference.uploadFailed')
onboardingTranslate(locale, 'comfy.enable')
scene3dTranslate(locale, 'fullscreen.screenshot')
```

Use named parameters for dynamic text:

```ts
t('library.project.deleteAria', { name: project.name })
```

## Pulling future Nomi updates

1. Merge or rebase the upstream Nomi update normally.
2. Resolve component conflicts by preserving `t(...)`, `canvasT(...)`, `onboardingT(...)`, or `scene3dT(...)` calls.
3. For any new hardcoded Chinese interface text, add keys to the appropriate dictionary before finishing the merge.
4. Run `pnpm run check:i18n` to catch direct Chinese UI labels, placeholders, toasts, prompts, and errors.
5. Run the full gate before shipping: `pnpm run gates`.

The gate now includes `check:i18n`, so future updates fail early if Chinese UI text is reintroduced outside the dictionaries.
